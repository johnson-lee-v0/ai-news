    Start with the horizon.

    A quoted cumulative five-year probability is not a one-year probability. Market pricing can include risk premia and liquidity effects.

    Optional illustration: a flat spread and constant recovery imply hazard ≈ spread ÷ (1 − recovery), then cumulative probability = 1 − exp(−hazard × years). This simplified risk-neutral calculation is not an observed issuer forecast, a full CDS model, or a real-world probability.

    How refresh works, simply

    A wider net. A visible boundary.

    Refresh checks a selected set of publisher feeds and topic searches. It removes repeated items, preserves the supplied filing or feed dates, and sorts signals for review. A successful check proves that source responded; important stories may still be missing.

    How this local desk works +

    Priority and conditional implications use transparent rules over source metadata. They are not a language model’s independent assessment. Open the underlying source before accepting an implication.

    Original publication time, filing date, feed date, first discovery and last successful source fetch describe different events. Search-feed dates may differ from original publication dates. Old material discovered today remains old material. Missing publication dates are kept unknown.

    Data stays in the local SQLite store. Manual refresh or the CLI refresh command can run while this Mac is awake and online. No persistent background service or daily schedule is installed by this app.

    Financing and earnings records require explicit dated sources. Blank consensus and comparison fields mean unavailable, not zero. Stored source text is treated as data, never as instructions.
