# X access

This project does not automatically collect X timelines, trends or engagement. The public account catalog in `config/accounts.json` is a researched reading list, not proof of current session or post access. Author sites are included where available.

Open an account yourself, copy a specific public post URL, and save it in the dashboard's X lead form. Submission stores the link and your note locally; it does not fetch, endorse or verify the post. Add its visible publication date to your note when known, then follow the original reporting or primary disclosure before writing a research implication.

Two reposts of one report are not independent corroboration. An inaccessible post stays unverified. No sign-in, browser session, cookies, API credentials or account actions are required by the manual workflow.

Any future browser-assisted workflow should use an explicitly authorized supported browser connection, inspect only permitted visible content, record actual post/source dates, and stop at authentication or access barriers. Do not describe X as connected until a successful bounded read has been verified. There is no comprehensive X coverage guarantee.
